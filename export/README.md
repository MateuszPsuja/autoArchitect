## OpenSpec export

`microblog-demo-OpenSpec.zip` is the OpenSpec-shaped bundle. It packages a
single `openspec/changes/<feature-slug>/` change folder with exactly five
files, structured so an OpenSpec-capable agent can run `/opsx:apply` against
it without further reformatting:

- `proposal.md` — Why / What Changes summary
- `design.md` — technical design
- `tasks.md` — implementation tasks
- `specs/<feature-slug>/spec.md` — feature spec (requirements + scenarios)
- `specs/<feature-slug>-architecture/spec.md` — architecture spec

artifact for projects scaffolding with [GitHub spec-kit](https://github.com/github/spec-kit).
